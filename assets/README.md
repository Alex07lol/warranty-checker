# Assets

Shared static assets for the WarrantyVault project.

## Structure

```
assets/
├── images/     - Project images, logos, and screenshots
├── icons/      - Application icons in various sizes
└── fonts/      - Custom font files if any are used beyond Google Fonts
```

App-specific assets used within the Flutter app (icons, images referenced in pubspec.yaml) are stored in `mobile/warranty_vault/assets/`.

This directory contains project-level assets such as the app logo for documentation and marketing purposes.
