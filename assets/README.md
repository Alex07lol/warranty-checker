# Assets

Shared static assets for the WarrantyVault project.

## Structure

```
assets/
├── images/     - Project images, logos, and screenshots
├── icons/      - Application icons in various sizes
└── fonts/      - Custom font files if any are used beyond Google Fonts
```

This directory contains project-level assets such as the app logo for documentation and marketing purposes. (The Flutter app that previously used `mobile/warranty_vault/assets/` was removed in August 2026 — the project is web-only.)
